> 版本：V0.1（2026-11-21，视觉一档改善启动）
> 撰写：产品经理 / 剧情策划（队友 Qoder）
> 关联：T-P4-1；替换对象 = `src/components/stage/PixelAvatar.tsx`（12×12 程序化占位）与 `src/components/stage/SceneBackground.tsx`（CSS 装饰）；风格样板见 `docs/asset-samples/`。

## 1. 目标与原则

- 把全部程序化占位（方块脸立绘、CSS 几何背景）替换为**正式像素素材**；组件对外接口不变（PixelAvatar 保持 `character/size` props，SceneBackground 保持 `scene` key）。
- 风格基线：16-bit 像素风、有限色板、光感克制、无写实纹理；冷/暖色调跟随章节基调（STORY_FLOW 各章「渲染基调」）。
- 生成方式不限（ImageGen / 手绘 / 素材站授权），但**必须同风格连作**；中文字一律不烧进图片（由 UI 文本层渲染，避免字形不可控）。
- 性能红线：全部新增素材压缩后合计 **≤ 2.5 MB**（2026-11-22 由 2MB 放宽，用于接入 5 张结局插画）；无图/加载失败时回退现有 CSS 占位（开发保证）。

### 14.1 听感标准（2026-11-27 产品负责人试听反馈：「太闷」）

新曲必须**不闷**，执行以下清单（验收时逐条对照）：

1. **去掉浑浊低频**：取消全程低频 drone 铺底（现 ch1 的主要闷感来源）；120Hz 以下低切（保留少量钢琴最低音即可），低频只作点缀。
2. **钢琴要有击键感**：每次触键要有清晰 attack（起音 transient），不做长衰减糊成一片；必要时叠一层极轻的高频泛音层提亮。
3. **旋律/琶音上移**：主织体放中音区（C4–C6），低音区只做根音支撑——禁止「全程低音区慢板」。
4. **留一点空气**：轻混响即可（湿声 ≤15%），并保留高频通透感；不要用大混响掩盖稀疏。
5. **40 秒内要有起伏**：至少一次力度/织体变化（渐强或加声部再退），避免全程同一力度。
6. **手机外放验收**：手机外放或普通耳机试听必须能听清钢琴轮廓（评委大概率外放）；只在监听耳机里清楚不算过。
7. **响度**：峰值约 −3dBFS，保留动态，不做过度压限；与现版 −18dB 播放音量下应比现版「亮」而非「响」。

若合成钢琴达不到成品感，可退一步：先用 CC0 授权钢琴曲候选（FreePD / Freesound CC0）试听择优，再决定自制或替代——两条路都需按本清单验收。
