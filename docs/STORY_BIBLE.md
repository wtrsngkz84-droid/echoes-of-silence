## 1. 一句话与故事梗概

**一句话**：一张被裁剪的聊天截图，让一个初中女生在四十八小时内失去整个班级——而截图的两端、屏幕后的每一个人，都将在这十二天里听见自己沉默的回声。

**梗概**：青禾中学初二(3)班的历史课调研汇报上，班主任李老师当众夸奖了报告的文本部分，并推荐作品参加校级「城市记忆」评选。组长周予安需要一个校级奖项去支撑下个月的学生会竞选，当晚私信组员林小满，希望「主要完成人」只填自己。林小满提出了更公平的方案：如实填写每个人的分工。这番被截图裁剪的话，加上一句「她放学专门去找了老师」的臆测，在周五晚上被周予安发进 46 人的班级群。群聊爆炸、表情包、匿名墙投稿接踵而至，林小满陷入无人开口的自证陷阱，她的座位第一次空了出来。十二天后，公示栏上贴出她当初申请的「分工说明页」，但纸能澄清事实，不能自动澄清人心——要止住回声，需要三个人各自做出决定：说出真相的受害者、交出完整的施暴者、不再删除消息的旁观者。

**矩阵使用规则**：
1. 任何一章的场景不得让角色说出/想到其不知情的信息（防穿帮）。
2. 玩家的跨章知识 ≠ 角色知识：玩家带着上一章信息进入下一章是设计乐趣（戏剧反讽），但角色行动依据必须在本章内自洽取得（例如陈屿不能凭空引用晓芸发帖，除非第三章内提供他自己的推理路径）。
3. ⊕ 错误认知的修正必须消耗证据或事件（如 12/7 公示、EV-05 证言），不允许「突然想通了」。

### 6.1 舆论为何转身：单薄证据的引爆机制（剧本检查清单）

回答一个必须让玩家信服的问题：**为什么一张只有一句话的截图，能让全班在四十八小时内孤立一个人？** 以下五条机制缺一不可，剧本阶段逐条落实为场景/台词，缺则补：

1. **预置印象（火种提前埋下）**：11/26 老师当众玩笑把「文本功劳」单独点名给转学生——「她受宠」的叙事底色先于截图存在，班级对她的善意库存本就薄弱。
2. **不可证伪的核心（真正的引信是 21:52，不是截图）**：「她专门去办公室找了老师，说了什么大家自己想」——这句臆测无法用任何截图反驳；而截图会被指「可 P」，完整记录同样会被指「可 P」。**自证陷阱的机制核心：受害者拿出的任何证据天然不被采信**，因为她是有利害关系的一方。
3. **最坏解读的娱乐性**：「组长练了十六遍 vs 白捡功劳」有故事性、可再创作（表情包、梗图）；「她其实在提议全组分工如实填写」没有传播价值。谣言传播靠有趣，不靠准确。
4. **异议即围攻**：当晚唯一质疑者被「圣母」标签即刻压制（§5-F），沉默的螺旋一晚上就完成合拢。
5. **善意不上场**：私信安慰只发生在私人窗口（12/1 起的「别理他们」），公共场域里受害者面对的是一整块沉默——孤立感由「沉默的可见性」构成。

主题落点（供文案统调，也是对玩家质疑的预埋回答）：**班级不是因为证据充分而转身，而是因为查证显得多余。** 因此澄清无法靠受害者自证，必须依赖第三方信源——陈屿的旁听、李老师的记忆、公示栏的程序性文件——这正是三视角结构的叙事必然性，而非巧合。

### 7.3 「最终发布版」规则（跨章一致性核心机制）

- 玩家在关键节点的选择若涉及**会形成客观记录的行为**（发到群里的话、交给老师的材料、发出去的消息），客观时间线只记录**最终发布版**，且最终发布版 = §5 定稿原文。
- 玩家的变体选择体现在**草稿层**：打字又删掉的版本、内心独白、私下的措辞倾向、烈度参数（如予安对表情包的态度：阻止/无视/放任）。
- 由此保证：无论玩家怎么选，第二、三章重演 11/27 群爆时，看到的原文与第一章完全一致（可逐字 diff）。

### 7.4 章内行为空间（「菜单即心理」原则）

1. **第一章（受害者）**：11/26–11/27 的爆发段为固定过场 + 反应选择（内心独白、是否回应安慰私信），玩家的真实选择空间从 11/27 夜的自证方式开始，到 12/4 后的求助路径完全打开。**设计原则：受害不是她的选择**——前半段低行动权本身就是主题的一部分，绝不允许出现「如果她当时说话方式更好就不会被霸凌」的暗示。
2. **第二章（施暴者）**：11/26–12/6 的升级段，菜单只提供「当时她眼中存在的选项」（措辞轻重、加码或放任），玩家体验到隧道视野；12/7 公示后菜单**逐渐长出**责任选项（自首、澄清、退选），菜单本身的扩张即她的觉醒过程。每一步都明示：「此刻的她，觉得这是全部选项。」
3. **第三章（旁观者）**：菜单从头到尾全开（沉默/私援/作证/公开发声），但每个选项旁标注它的「价格」（被围攻、被连坐、被说圣母），玩家的每个选择都是明知代价的道德决策。匿名纸条（EV-09）为固定小事件（他塞了，玩家只选草稿措辞，最终发出 §5-K 原文）。

| 外形像素要点 | 齐耳短发 + 一枚旧发卡；蓝白校服穿得整齐；永远抱着帆布包（里面有一本书和草稿本）；整体冷色调、低饱和 |
| 性格内核 | 话少而准，书面语会不小心脱口（「这样对大家都公平」式的认真）；对文字有近乎虔诚的信任——她相信「写清楚」就能解决误会，这个信念在本事件中被击碎又重建 |

| 设计红线 | 任何文本不得暗示「她本可以更好地避免」；她的迟钝于求助是环境与性格的合谋，伤害的责任在施暴方与失语的集体 |

### 9.2 周予安（视角角色：施暴者，第二章）

| 项 | 内容 |
| --- | --- |

| 外形像素要点 | 高马尾、校服外套袖口卷起、别着学生会徽章；暖橙点缀色、姿态挺拔、占空间 |
| 性格内核 | 外向、组织力强、要强到脆。她确实为汇报排练了 16 遍、跑了三趟老街——**她的辛苦是真的，这恰恰是本作的道德重心：真实的付出不能兑换伤害他人的权利** |
| 施暴动机解剖（理解 ≠ 开脱，两者并置且互不抵消） | 四层堆叠：①老师玩笑当众刺痛（「我讲汇报，功劳归文本」）→ ②私聊被「拒绝 + 说教」（她读成羞辱）→ ③晓芸的办公室臆测（火上浇油）→ ④「她已经拿到第一完成人，但荣誉感被夺走的体验不因此消失」。她发截图时坚信自己在「讨公道」 |
| 自我辩护话术链（第二章逐层解剖） | 「我只是让大家评评理」→「我发的哪一句是假的？」（她截的那句话一个字不假——谎在裁掉的部分与配文的暗示，断章即谎言）→「表情包又不是我做的」→「现在退出去，前面那些算什么？」 |
| 心理弧线（第二章） | ①委屈自证 → ②点火（裁剪发布）→ ③被拥护的快感（误把声量当正义）→ ④失控（表情包不是她做的；归属表排版和树洞帖口气都让她隐约猜到是晓芸——**不问就不必负责**，这是她的「选择性不问」）→ ⑤反噬（空椅子入梦、公示碎裂她的叙事、竞选逼近）→ ⑥三岔：加码压制 / 冷处理等风头 / 自首担责 |

| 语言习惯 | 快、密、反问句多、爱用感叹号和 [表情]。「大家评评理？」「我又没撒谎。」后期（12/8 后）出现她标志性的删改：「对不起」打了又删——删掉的内容会显示在玩家的输入框残影里 |
| 设计红线 | 不用「原生家庭」为她免责（家庭解释她的形状，不豁免她的行为）；她的人性化只能通过「她的痛苦是真的」来实现，绝不通过「她其实情有可原」；担责路径必须付出真实代价（退选、处分），无低成本洗白 |

### 9.6 罗一鸣与班级群像（功能性 NPC）

- **罗一鸣**（班长、群主）：和事佬，「行了行了别刷了」式维稳，象征班级自治的无力——他能管秩序，管不了沉默。
- **起哄型**（3–5 人）：玩梗、@小满 说话呀、压制异议（「哟 圣母出来了」）。
- **围观型**（大多数）：只看不说或 +1。**沉默的大多数是本作真正的「群主角」**。
- **私信安慰型**（2–3 人）：私聊「别理他们」，群里绝不开口——「安全的好意」，与陈屿互为镜像。
- **疑问型**（1–2 人）：小声质疑即被围攻噤声——展示异议压制机制。
- 群像发言者一律使用昵称化 handle（具体昵称在剧本阶段定），不给全名，避免配角膨胀。

## 11. 贯穿意象（Motifs，跨章复用）

| 意象 | 含义与用法 |
| --- | --- |
| 空椅子 / 座位 | 全作核心意象（章一标题）。小满不敢坐下（12/1）→ 座位空着（11/30）→ 陈屿速写本里每页的空椅子 → 予安梦里越坐越远的椅子 → 班会上椅子是否被坐回（结局判定画面） |

## 12. 三章结构与结局候选概要

> 流程与判定的完整细则在 STORY_FLOW / GAMEPLAY_DESIGN（P2 交付），本节只锁结构。

### 第一章「空出来的座位」（林小满，11/26 晚 – 12/8）

场景序列：①汇报课（被点名的不安）→ ②办公室（她的善意将遭到扭曲的种子）→ ③私聊之夜（固定过场 + 反应选择）→ ④群聊之夜（核心交互：消息流、自证方式选择、被围攻、退群）→ ⑤冷暴力蒙太奇（缺席日、返校、归属表、纸条、12/3 门口中断）→ ⑥12/4 后求助路径选择（妈妈 / 李老师带草稿本 / 陈屿 / 谁也不找）。章末：回声小结 + 她的选择之夜。

### 第二章「失控的群聊」（周予安，11/26 – 12/12）

场景序列：①汇报课（台上视角）→ ②私聊之夜（发送端）→ ③点火之夜（晓芸电话 → 裁剪 → 发布 → 被拥护感）→ ④失控蒙太奇（表情包惊愕；归属表排版引发的「是晓芸？」猜测与「选择性不问」；树洞帖同样不问；空椅子入梦）→ ⑤公示反噬（叙事碎裂 + 竞选倒计时）→ ⑥12/8–12/12 责任三岔（加码 / 冷处理 / 自首 + 退选）。章末：她的选择落点，从她的位置看到的结局前奏。

### 第三章「沉默的旁观者」（陈屿，11/26 – 12/14）

场景序列：①值日旁听（全知起点）→ ②群聊之夜（输入框与已删除的消息——核心交互）→ ③沉默的记账（速写本、捡本子、塞纸条）→ ④12/4 教室独处（说多少、给不给看照片）→ ⑤公示后的窗口（证据在手：照片、旁听、完整记录）→ ⑥12/8–12/11 行动选择（沉默 / 私援 / 交证据 / 公开发声及其标价）→ 班会 → **结局判定与回声终章**（结局在三线状态合成后统一结算）。

### 结局候选（5 个，判定细则 P2 定稿，提案见决策 P-010）

| 代号 | 名称 | 触发骨架（三线状态合成） | 核心画面 |
| --- | --- | --- | --- |
| E1 | 沉默的代价 | 三线均失败（未求助 / 加码 / 沉默且可含跟风） | 学期末小满转学，座位第二次空出来；予安赢得竞选；树洞帖渐渐无人记得；速写本最后一页是空椅子，角落一行小字「对不起，我删掉了那句话」 |
| E2 | 及时止损 | 无主动求助与担责，仅被动介入（公示 + 零星线索） | 谣谣澄清但责任未落定；小满留下来，「上课不再举手」；班级学到的唯一一句是「别再闹大」 |
| E3 | 再次求助 | 小满线达标（证据 + 求助成功）；予安线任选（影响尾声文案） | 处理落地；小满把帆布包放回桌上，给妈妈发「妈，今天我想跟你说个事」——打字，删掉，再打，发送 |

| E5 | 回声（真结局） | 三线全部达标 | 班会 + 自发的匿名道歉墙（「当时我转发了」「我没说话」「对不起」贴满一栏）；空椅子归还；小满坐回，说：「椅子我坐回来了。剩下的，慢慢来。」陈屿先鼓掌 |

## 13. 创作红线与执行规则（写作时的可检查规则）

以下把 PROJECT_CONTEXT §5 的原则翻译为逐条可执行的写作规则，剧本与验收阶段逐条对照：

1. **不责怪受害者**：任何场景不得出现「如果她当时……就不会……」因果暗示；小满的性格特质（话少、较真、求助慢）只作为「她是这样的人」呈现，不作为风险因素呈现；她的一切选择（含不求助）在文案中的定性是「她在自保」，不是「她犯错」。
2. **求助永远优于不求助**（结局与文案层面）：求助受挫的路径也要留下「老师开始留意」等正向痕迹；禁止设计「求助反而更糟且无补偿」的路径。
3. **不为施暴者开脱**：予安的付出与痛苦必须呈现（人性化），但每次呈现同场景内必须有责任事实并置（她已得到第一完成人名义、裁剪是她亲手所为、臆测是她亲手发布）；禁止「她也被网暴了所以扯平」式对等叙事。
4. **不强迫原谅**：所有好结局中，小满对道歉的回应上限是「接受道歉 + 明确不承诺原谅」；禁止任何结局出现拥抱、和好、闺蜜式和解画面。
5. **旁观者安全路径**：私下支持与告诉老师被游戏明示为「正确且安全」的路线；公开发声呈现为「勇敢但有代价」的可选项而非道德义务；跟风分支如实呈现其重量，禁止廉价洗白（跟风者若不补救，结局文案不给他免责）。
6. **不过度展示伤害**：伤害以缺席、静默、日常细节表达（空椅子、饭量、字迹变轻）；禁止自伤/自杀情节与画面、禁止血腥刺激、禁止详细的心理折磨过程描写。
7. **成人不是救世主也不是废物**：李老师会犯错会纠错；家长线（小满母亲）提供情感支持但不越俎代庖解决问题。
8. **不作知识宣讲**：主题全部通过剧情后果承载；禁止任何角色长篇说教（李老师班会台词控制在三句以内）。
9. **虚构性**：所有人名、地名、机构、平台均为虚构或泛化；不出现可对号入座的真实学校与真实事件细节。
10. **可开发性**：每个场景、选项、证据、状态变化必须能落到节点数据（DEV_HANDOFF 接口）；写剧情时同步标注所需资源与占位方案。
