## 1. 文档定位与编号约定

| 项 | 约定 |
| --- | --- |
| 场景节点 | `C{章}-{两位序}`，如 C1-05；三章依次 C1/C2/C3 |
| 选择点 | `CP{章}-{序}`，标注于所属场景行内，如 C1-CP1（第一章第一个实质选择点） |
| 3 分钟路径节点 | `S{序}`，仅用于双入口 B（§3） |
| 节点类型 | 固定过场（无选择）/ 反应选择（不影响客观记录，写内心与微动作）/ 核心交互场景（专用交互机制）/ 蒙太奇（多日压缩）/ 行动窗口（多步选择区）/ 章末小结 |
| 状态变量 | 命名与取值域见 GAMEPLAY_DESIGN §5；本文件只写「写入哪个变量」 |
| 原文引用 | 引用 STORY_BIBLE §5 时逐字使用，节点表「引用」列标明条目号 |

**流程设计总原则**（对应 PROJECT_CONTEXT「有后果的互动」）：

1. 每个选择点至少改变一处状态变量或解锁一处后续文案差异；禁止「假选项」（PRD FR-02）。
2. 客观记录类行为服从「最终发布版」规则（STORY_BIBLE §7.3）：玩家变体存于草稿层，最终发布文本 = §5 定稿原文。
3. 跨章数据只向前流动（Ch1→Ch2→Ch3→结局），详见 GAMEPLAY_DESIGN §6。

## 2. 全局流程总览（完整体验主线）

```
开始屏（内容提示 FR-10 + 双入口 FR-13）
 ├─ 入口 A「完整体验」→ C1-01 …（全流程，约 10–15 分钟）
 └─ 入口 B「3 分钟体验」→ S1 …（§3）
       完整体验：
C1-01 序章 → C1-02 汇报课 → C1-03 办公室 → C1-04 私聊之夜 → C1-05 群聊之夜★
→ C1-06 缺席日 → C1-07 冷暴力蒙太奇 → C1-08 12/4 独处★ → C1-09 求助路径★
→ C1-10 回声小结 → [视角切换] C2-01 …第二章 → C2-09 回声小结
→ [视角切换] C3-01 …第三章 → C3-06 行动窗口★ → C3-07 班会（三线合成）
→ C3-08 结局判定与回声终章 → C3-09 尾声与出口（资源页 + 章节回顾 + 重玩）
```

★ = 核心交互场景。每章开头的视角切换卡固定演出：「第一章 空出来的座位——这一次，你站在林小满的位置。」（二、三章同款句式）。

## 3. 3 分钟评审路径（FR-13 入口 B）

对应 PRD FR-13 与作品帖「怎么用 5 步以内」要求。设计原则：**使用与完整体验完全相同的交互机制与 §5 原文**——3 分钟版本是同一游戏的浓缩，不是另一个游戏。

| 节点 | 内容 | 时长 | 玩家动作 | 复用的完整版机制 |
| --- | --- | --- | --- | --- |
| S1 | 群聊爆炸夜（小满侧）：11/27 消息流刷屏 → 自证方式选择 | ~50s | 1 次选择（C1-CP1 四选项） | 消息流 + 截图查看器（FR-04） |
| S2 | 裁剪之夜（予安侧）：「你刚刚被围攻的那句话，是你亲手裁出来的」→ 执行裁剪 | ~60s | 裁剪交互（选 20:33 入图） | 裁剪交互（GAMEPLAY_DESIGN §3.3） |
| S3 | 输入框（陈屿侧）：打出那句话，发送或删除 | ~40s | 发送 / 删除（高风险分支如实呈现） | 输入框 + 已删除消息存档（§3.4） |
| S4 | 12/8 行动窗口快切：三线各一关键选择（小满求助方向 / 予安三岔 / 陈屿行动等级） | ~50s | 3 次选择（各取对应 CP 的核心选项） | 行动窗口菜单 |
| S5 | 结局结算（按 S4 三选合成）+「这是完整体验的十分之一」引导 + 两个入口（进入完整体验 / 重新选择 3 分钟） | ~30s | 结局画面 + 跳转 | 结局判定矩阵 |

- 合计约 3 分钟；S5 的结局画面素材与完整版同一数据源（结局文案表）。
- 3 分钟路径的状态使用独立命名空间（`3min_` 前缀），不污染完整版存档（GAMEPLAY_DESIGN §5.4）。
- S4 中玩家若选「谁也不找 / 冷处理 / 沉默」，S5 结算出 E1/E2 类结局——**允许**：3 分钟路径不保证好结局，后果真实性是卖点；但 S5 结尾固定追加一屏「完整体验里，你还有十二天。」的引导文案。

## 9. 回声小结（章间）设计

每章末一屏（C1-10 / C2-09 / C3-08 前奏）：

1. **本章选择摘要**：2–4 行，只陈述不评判（「她把完整记录保存了下来。」「她问了一句，又咽了回去。」）。

3. **视角引导**：「下一章，你会从另一个位置，重新经过同一周。」（固定的三视角结构显性提示，FR-06）。
