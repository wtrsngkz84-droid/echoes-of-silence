## 1. 产品概述

| 项目 | 内容 |
| --- | --- |
| 名称 | 沉默的回声（Echoes of Silence） |
| 类型 | 2D 像素风多视角互动叙事游戏（视觉小说 + 调查/线索 + 聊天记录交互） |
| 平台 | PC 浏览器（React + TypeScript + Vite + CSS，LocalStorage 存档，无后端） |
| 一句话定位 | 玩家先后扮演同一场校园网络暴力事件中的受害者、施暴者与旁观者，亲历同一张截图的三种真相，并用自己的选择决定回声如何落下。 |
| 核心创意 | **同一事件、三个视角、一套共享事实**：三个章节重演同一时间线，玩家携带上一章的「上帝视角」进入下一章的角色「信息茧房」，信息差即玩法。 |
| 赛道 | LifeHack 生活娱乐（团队自选方向；官方赛道定义已核实，见 PROJECT_DECISIONS §4.1） |

## 2. 设计目标与非目标

### 2.1 目标

1. **娱乐体验是产品形态**：完整的游戏（剧情推进、选择、分支、多结局、收集），不是宣传页或问答程序。
2. **教育价值是剧情内核**：自证陷阱、群体极化、沉默的代价、责任的重量等主题全部通过「玩家亲身操作」承载，不做说教式宣讲。
3. **有后果的选择**：每个选择改变状态与后续剧情，结局由三条视角线的行为合成。
4. **安全的表达边界**：不责怪受害者、不为施暴者开脱、不强迫原谅（执行细则见 STORY_BIBLE §13）。

### 2.2 非目标（明确不做）

- 不做知识问答、答题评分、普法宣传页。
- 不做账号系统、云存档、跨设备同步（第一版 LocalStorage 即可）。
- 不做多语言、移动端适配优化（PC 浏览器优先）。
- 不做心理咨询或求助热线服务本身（只提供提示与公开渠道信息）。
- 不做成就、支线、隐藏剧情等扩展（P2，核心体验完成后再评估）。

## 3. 目标用户与场景

| 用户 | 画像 | 诉求 | 产品响应 |
| --- | --- | --- | --- |
| 主用户：初中/高中学生 | 13–18 岁，熟悉班级群、匿名墙等社交场景 | 好玩、代入、想知道「如果我选了会怎样」 | 三视角代入、群聊交互、多结局重玩 |
| 次用户：教师、家长 | 关心校园关系议题的成年人 | 理解孩子遭遇、找到可讨论的素材 | 章节回顾、内容提示、无操作门槛 |
| 评审/展示观众 | 比赛评委、路人玩家 | 短时间理解亮点 | 核心样片（约 3 分钟）即可体验完整核心机制 |

## 4. 核心体验与时长目标

- **核心样片（V0.1）**：第一章「群聊之夜」单场景——手机群聊界面全交互（消息流阅读、自证方式选择、被围攻、退群），约 3 分钟，覆盖游戏最具辨识度的机制。
- **完整体验（V1.0）**：三章 + 结局 + 回声终章，约 10–15 分钟；多结局探索可重玩。
- 官方语境（2026-11-11 核实，见 PROJECT_DECISIONS §4.1）：LifeHack 赛道示例为「互动叙事与生成式玩具、可以在浏览器里玩 3 分钟的东西」——「3 分钟」是赛道示例风格而非硬性上限；但作品须「评委点开就能访问」且作品帖要求「怎么用（5 步以内，评委照着能自己打开用起来）」。
- 因此 V1.0 必须**双入口**：打开作品链接即见「3 分钟体验 / 完整体验」选择，评委短时间也能走完核心机制；剧本完成后按实际文本量复测时长，必要时压缩单场景文本密度。

## 7. 内容与安全要求

1. 全部人物、学校、群聊、事件均为虚构；开场与结尾标注虚构声明。
2. 不收集玩家任何个人信息（姓名、真实经历、真实聊天记录）；无输入自由文本的环节（选项制），如后续增加输入功能须重新评审。
3. 伤害表达有边界：不出现自伤、自杀情节与画面；最坏结局为「转学离开/长期空座」，以静默与缺席表达代价，不以血腥或极端画面刺激。
4. 内容提示 + 随时退出；正文不出现真实联系方式（求助渠道集中在资源页）。
5. 表达原则红线（不责怪受害者/不为施暴者开脱/不强迫原谅/旁观者安全帮助路径）作为验收项（见 STORY_BIBLE §13 与 ACCEPTANCE_CRITERIA 表达原则部分）。

## 8. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 部署 | **Qoder Sites 公网部署并公开访问**（官方硬性要求，2026-11-11 核实：作品链接须为「Qoder Sites 部署后并设置为公开访问的地址，评委点开就能访问」，原则上不接受本地文件与压缩包）。部署操作为开发负责人主责 |
| 浏览器 | Chrome/Edge 最近两个大版本（P0）；Firefox（P1）；不支持 IE |
| 性能 | 首屏可玩 < 3 秒（普通家用网络，评委点开即玩的硬前提）；剧情场景切换 < 300ms；资源懒加载 |
| 可访问性 | 字号可调（至少两档，P1）；对比度满足正文可读；纯键盘可推进（P1） |
| 语言 | 简体中文；面向初中生可读，避免生僻词（专有名词随剧情解释） |
| 存档 | LocalStorage；存档结构版本化，升级兼容策略由开发定（TECHNICAL 记录） |
